# UX principles

Pooli follows interaction guidance from Apple Human Interface Guidelines (hierarchy, 44pt targets, tabs as destinations, progressive disclosure, sheets, reduced motion). Visual identity is Pooli’s, not Apple’s.

Material Design is used only for form errors, focus, and state communication — not Android look.

Nielsen Norman heuristics we optimize for: recognition over recall, match to the real world, visibility of status, error prevention, minimalist design, user control, consistency.

## Hierarchy

In two seconds a merchant should know: what this page is, what to do next, and whether they got paid.

## Navigation

Tabs are destinations: Home, Orders, Customers, Settings. **New payment is an action**, not a tab.

## Feedback

Status is written in words (`Paid ✓`, `Waiting for payment`). Color is never the only signal.

## Mobile first

Design for ~390px. Desktop may widen; it must not dictate architecture.

## Screenshot test

Show a screen for five seconds with no context. If “what is this?” and “what next?” disagree, the hierarchy is still wrong.

# Illustration

Small, warm, recognizable. Support the idea: **money arriving simply**.

## Motifs (keep the set small)

Source SVGs in `.local-brand-studio/illustrations/source/`:

1. `01-send-the-link` — a link leaving a chat
2. `02-payment-arriving` — quiet arrival, not a coin
3. `03-paid-check` — the status as the picture (`03-paid-check-motion` for the draw)
4. `04-receipt-chaos` — the enemy
5. `05-direct-to-wallet` — money going to *their* address

## Do

- Quiet scenes: a link, a check, a phone, a shop counter
- Flat or lightly dimensional, Pooli mint + ink
- Stroke 3–6px
- Persian-first compositions when the audience is FA
- One motif per frame

## Don’t

- Floating coins, Bitcoin logos, astronauts
- Generic 3D fintech blobs
- Neon, glass stacks, dashboard mock clutter

Production files: `.local-brand-studio/illustrations/` (gitignored).

# Navigation

Mobile: 4-column bottom tab bar (`.nav`), 44pt-class hit area, blur with solid fallback.

Desktop (≥900px): same four destinations remain in the tab bar (mobile/PWA wins). A compact **New payment** button appears in `.app-topbar` on Orders, Customers, and Settings — not on Home (hero CTA), Create (already there), or order detail (Share owns the screen).

Create (`/app/create`) is not a tab. No tab is active there.

Onboarding hides the tab bar.

# Design references

Principles Pooli follows (do not copy proprietary UI or copyrighted HIG text into this repo):

- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) — hierarchy, navigation, progressive disclosure, 44pt targets, sheets, accessibility. Local token reference clone: `hig-mcp` (not an Apple visual identity).
- [Material Design](https://m3.material.io/) — forms, errors, focus; not visual skin.
- [Nielsen Norman Group heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/)

Interaction patterns (not branding) from calm payment products: Apple Wallet status, simple “amount → share” create flows.

Token implementation: [`apps/web/src/app/globals.css`](../../apps/web/src/app/globals.css).

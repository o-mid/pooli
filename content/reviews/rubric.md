# Independent review rubric

Run after a workstream, not while it is drafting. One reviewer hat at a time.

## Claims

- [ ] Every feature sentence survives `content/messaging/claims.md`
- [ ] Instagram composer is not sold as live
- [ ] Phone OTP is not sold as live
- [ ] No GMV, merchant count, testimonial, investor, legal entity
- [ ] Demo screens labeled (تهران اسنیکرز)

## Voice

- [ ] Sounds like a person, not a launch template
- [ ] Contractions OK; no “Thrilled to announce”
- [ ] FA is spoken Persian, not translated UI
- [ ] پولی never پولیی
- [ ] CTA is quiet (pooli.shop / لینک رو بفرست)

## Visual

- [ ] Tokens from `globals.css` only
- [ ] Mint is a result color, not wallpaper (≤2/10 frames)
- [ ] No coins, neon, glass, fake iPhone-as-the-design
- [ ] Type readable at the real crop size
- [ ] Deck: big type, whitespace, two decks are not clones

## Social native

- [ ] X is not a chopped LinkedIn post
- [ ] LinkedIn founder ≠ company
- [ ] Calendar has empty days
- [ ] Handles marked unchecked

## Kill list (automatic reject)

Revolutionary / seamless / trusted by / unlock / supercharge / “we’re live!” with no payload / fake TAM / coming-soon waitlist (site is live) / SMS login / Instagram payments today
